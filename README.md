## 🌿 Featured work: the NSW biodiversity credit market

A three-part study of the NSW Biodiversity Offsets Scheme, built from the government's public registers. Each project answers one question.

| Project | Question | Key finding |
|---|---|---|
| [**Credit Gap Analysis**](https://github.com/Likithaa07/nsw-biodiversity-credit-gap) | Which credit types are running out? | 43 of 305 credit types in demand have **zero supply**, and 71 have less than a year left. |
| [**What Drives Credit Prices?**](https://github.com/Likithaa07/bos-credit-prices) | Do scarce credits cost more? | Location and vegetation type explain most price variation (adj. R² 0.71, 1,284 sales). Within the same region, there is **no robust scarcity premium**. |
| [**Credit Opportunity Map**](https://github.com/Likithaa07/nsw-credit-opportunity-map) | Where could new supply come from? | Mapped 860,669 ha of remnant vegetation and ranked 132 IBRA subregions for new stewardship sites. |

**Deliverables:** Power BI dashboard · findings report · data quality report · data dictionary · policy briefing note · ANZLIC metadata
